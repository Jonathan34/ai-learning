# Phase 5: AI Workloads

This is the bridge from AI application code to the machines underneath it.

The goal is not to become an ML researcher. It is to understand what training and inference ask from memory, compute, networking, storage, and schedulers. Once those mechanics are clear, infrastructure choices stop looking like a list of products.

Read these chapters in order:

1. Distributed training systems
2. Self-hosted inference
3. Workload sizing and economics

By the end, you should be able to turn a workload description into a first-pass platform design with explicit assumptions.
