# Phase 5: AI Workloads

This is the bridge from AI application code to the machines underneath it.

The goal is not to become an ML researcher. It is to understand the main ML problem types, what training and inference ask from a platform, and how models move safely into production. Once those mechanics are clear, infrastructure choices stop looking like a list of products.

Read these chapters in order:

1. ML algorithms for architects
2. Distributed training systems
3. Self-hosted inference
4. Workload sizing and economics
5. The MLOps lifecycle

By the end, you should be able to turn a use case into a first-pass model, lifecycle, and platform design with explicit assumptions.
