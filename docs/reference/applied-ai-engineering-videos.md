## Watch actively

For each video, write:

1. What customer problem is being solved?
2. What is measured?
3. Which part needs a model?
4. What can fail outside the model?
5. Which claim would you verify in the current documentation?

Do not memorize old product limits or model names from a video. Check the
[official API documentation](https://developers.openai.com/api/docs) before
using them in a design.
