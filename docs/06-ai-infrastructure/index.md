# Phase 6: AI Infrastructure

This phase follows an AI workload through the platform:

```text
model code
  → GPU memory and compute
  → GPU-to-GPU communication
  → datasets and checkpoints
  → scheduling and orchestration
  → repeatable infrastructure
  → health, performance, and recovery
```

Each layer can make an expensive cluster look slow. The useful skill is not memorizing every product. It is knowing which layer should carry which traffic, what good looks like, and how to isolate a fault.
